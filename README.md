# 🚀 **AI: Intelligent Symptom Checker**  

**Predict diseases with AI-powered accuracy!**  

---

## 🌟 **Key Features**  

✅ **Smart Symptom Analysis** – Get instant predictions based on your symptoms  
✅ **Organized Categories** – Easily find symptoms with intuitive grouping (Skin, Respiratory, Digestive, etc.)  
✅ **Multiple Predictions** – Top 3 possible diseases with confidence scores  
✅ **User Feedback System** – Share your experience to help improve accuracy  
✅ **Secure & Private** – No personal data stored permanently

## 🛠 **Quick Setup**  

### **1. Clone & Install**  
```bash
git clone https://github.com/yourusername/Al-Symptom-Checker.git
cd symptom-checker
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```

### **2. Run the App**  
```bash
python app.py
```
🔗 **Open in browser:** [http://localhost:5000](http://localhost:5000)

## 🔍 **How It Works?**  

1. **Select Symptoms** → Choose at least 3 from categories  
2. **AI Prediction** → Get top 3 possible diseases  
3. **View Results** → Confidence scores & details  
4. **Give Feedback** → Help improve the model!
